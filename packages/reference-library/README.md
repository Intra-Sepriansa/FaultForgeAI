# @faultforge/reference-library

Verified Reference Solutions Library & SRE Postmortem Generator for FaultForge AI.

## Features
- **Case Study Compiler**: Formats resolved incidents into structured, auditable post-incident case studies.
- **Reference Indexer**: Fast in-memory and database search indexer for historical incident remediation patterns.
- **SRE Postmortem Generator**: Automated Google SRE and PagerDuty compliant Markdown and JSON postmortem generation.
